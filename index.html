Core OS Architecture & Pillars

The four foundational responsibilities every modern operating system executes.

Resource Allocation & Scheduling

The OS acts as the ultimate manager, dividing finite resources—CPU time, memory space, and I/O access—among countless competing applications fairly and efficiently.

Hardware Abstraction

It shields developers from complex hardware specifications by providing a clean, unified API. Programs can save a file without needing to understand how a spinning hard drive or NVMe SSD physically operates.

Security & Isolation

By confining applications to isolated memory spaces (Virtual Memory) and managing user permissions, the OS ensures a rogue or buggy program cannot crash the entire system or steal data.

File & Data Management

It transforms raw magnetic tracks and flash blocks into a logical, human-readable hierarchy of folders and files, handling the complexities of journaling and data integrity.

OPERATING SYSTEMS

U24PC540IT Credits: 3

L:T:P (Hrs./week): 3:0:0 • CIE: 40 Marks • SEE: 60 Marks (Duration: 3 Hours)

Course Objectives
  1. Demonstrate the principles of modern operating systems and functionalities.
  2. Discuss the services of major operating systems such as Windows and Linux.
Course Outcomes (COs)
  • CO1 Understand OS functionalities, processes, threads, and evaluate CPU scheduling algorithms.
  • CO2 Apply contiguous & non-contiguous techniques for main memory management.
  • CO3 Design solutions for classical synchronization problems and deadlock strategies.
  • CO4 Implement techniques for file organization, I/O operation, and system protection.
  • CO5 Compare and contrast key features of Windows, Linux, and Android OS.
Unit-by-Unit Overview
UNIT - I
Introduction & Process Management

OS functionalities, system calls, boot. Process concept, threads, uniprocessor scheduling, multiprocessor/real-time scheduling.

Launch CPU Simulator
UNIT - II
Memory & Virtual Memory

Swapping, contiguous allocation, paging, segmentation. Demand paging, page replacement (FIFO, LRU, Optimal), thrashing, kernel memory.

Launch Paging Simulator
UNIT - III
Process Sync & Deadlocks

IPC, Peterson's solution, Bakery algorithm, semaphores, monitors, classical sync problems. Deadlock prevention, avoidance (Banker's Algorithm), recovery.

Banker's Dining Philosophers Readers–Writers
UNIT - IV
Storage and I/O Management

File concepts, mounting, directory structures, allocation methods, free space. Disk structure, RAID levels, disk scheduling (FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK), protection domain & access matrix.

Launch Disk Simulator
UNIT - V
Case Studies: Windows, Linux & Android

Windows 10 (Design, subsystems, NTFS). Linux (Kernel modules, CFS scheduler, VFS, IPC). Android OS (Software stack, activity lifecycle, intents, UI Material Design).
