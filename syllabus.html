Under Graduate Core Curriculum

OPERATING SYSTEMS

Theory, Architectural Foundations, and Practical Implementation

Simulators
Course Code: U24PC540IT
Credits: 3
L:T:P: 3:0:0 (Hrs./week)
SEE Marks: 60 (Duration: 3 Hours)
CIE Marks: 40

Course Objectives

The foundational objectives students will cultivate:

  1. Modern Principles & Functionalities: Demonstrate the core principles of modern operating systems, virtualization, and system functionalities.
  2. System Services & Architectures: Discuss and dissect the services of major contemporary operating systems such as Windows, Linux, and Android.

Course Outcomes (COs)

5 Outcomes

On successful completion of the course, students will be able to:

CO 1
Understand the functionalities of Operating Systems, Processes, threads, and evaluate CPU scheduling algorithms.
CO 2
Apply contiguous & non-contiguous techniques for main memory management and virtual memory.
CO 3
Design solutions for classical problems of synchronization and evaluate strategies for deadlock handling.
CO 4
Implement techniques for file organization, I/O operations, disk scheduling, and system protection.
CO 5
Compare and contrast key features and architectural functionalities of Windows 10, Linux, and Android OS.

Detailed Unit Syllabus

Complete syllabus divided across five comprehensive pedagogical units.

UNIT - I
Lecture Slides (8 Decks) CPU Simulator

Introduction and Process Management

Mapped Outcome: CO 1
Covers OS fundamentals, user interface, system call dispatching, thread architectures, and uniprocessor/multiprocessor scheduling heuristics.
OS Overview & Interfaces
  • Operating System Functionalities
  • Types of Operating Systems
  • User Operating System Interface (CLI vs GUI)
  • System Calls & System Boot Sequence
Process Concept & Scheduling
  • Process Concept: Overview, PCB, State Model
  • Threads (User-level & Kernel-level threads)
  • Uniprocessor Scheduling: FCFS, SJF, SRTF, Priority, Round Robin
  • Multiprocessor & Real-Time Scheduling Algorithms
UNIT - II
Lecture Slides (6 Decks) Page Replacement Simulator

Memory Management & Virtual Memory

Mapped Outcome: CO 2
Addresses main memory allocation, address binding, segmentation, paging tables, demand paging, and page replacement strategies.
Main Memory Management
  • Memory Background & Address Binding
  • Swapping Mechanisms
  • Contiguous Memory Allocation (Fixed & Variable Partitioning)
  • Paging Architecture & Translation Lookaside Buffers (TLB)
  • Segmentation & Segment Tables
Virtual Memory Management
  • Demand Paging & Page Fault Handling
  • Page Replacement Algorithms: FIFO, LRU, MRU, Optimal, LFU
  • Thrashing, Working Set Model & Page Fault Frequency
  • Allocating Kernel Memory (Buddy System, Slab Allocator)
UNIT - III Lecture Slides (7 Decks)

Process Synchronization & Deadlocks

Mapped Outcome: CO 3
Inter-process communication, race conditions, hardware and software synchronization primitives, and deadlock prevention/avoidance.
Process Synchronization
  • Inter-Process Communication (IPC)
  • Critical Section Problem & Requirements
  • Software Solutions: Peterson's Solution, Lamport's Bakery Algorithm
  • Semaphores (Binary & Counting) & Mutexes
  • Monitors & Condition Variables
  • Classical Problems: Producer-Consumer, Readers-Writers, Dining Philosophers
Dining Philosophers Readers–Writers
Deadlocks
  • System Model & 4 Necessary Conditions for Deadlock
  • Resource Allocation Graph (RAG)
  • Deadlock Prevention & Deadlock Avoidance
  • Banker's Algorithm: Safety & Resource-Request Algorithms
  • Deadlock Detection & Recovery Strategies
Launch Banker's Simulator
UNIT - IV Lecture Slides (4 Decks)

Storage and I/O Management

Mapped Outcome: CO 4
File system interfaces and internal structures, secondary disk scheduling, RAID redundancy levels, and protection domains.
File System Concepts & Structures
  • File System: Basic Concepts & Attributes
  • File System Structure & Mounting
  • Directory Structure (Single, Two-level, Tree, Acyclic)
  • Allocation Methods: Contiguous, Linked, Indexed
  • Free Space Management (Bit vector, Linked list, Grouping)
I/O Management & Protection
  • Disk Structure & Disk Scheduling (FCFS, SSTF, SCAN, C-SCAN)
  • RAID Structures & Levels (RAID 0 through 6)
  • Goals and Principles of Protection
  • Domain of Protection & Access Matrix Model
  • Implementation of Access Matrix (Access lists, Capability lists)
UNIT - V Comparative Systems

Case Studies: Windows 10, Linux, and Android OS

Mapped Outcome: CO 5
Architectural deep dive into production modern operating systems across enterprise desktop, server/cloud kernel, and mobile paradigms.
Case Study: Windows 10
  • Design Principles & System Architecture
  • Executive & Kernel Subsystems
  • Terminal Services & Fast User Switching
  • NTFS File System & Networking Stack
  • Win32 / Universal Windows Platform (UWP) Interface
Case Study: The Linux System
  • Design Principles & Monolithic Modular Kernel
  • Loadable Kernel Modules (LKM)
  • Process Management & Completely Fair Scheduler (CFS)
  • Virtual Memory Architecture in Linux
  • Ext4 File System & Virtual File System (VFS)
  • Input/Output & IPC (Pipes, Message queues, Shared memory)
Case Study: Android OS
  • Introduction to Android OS & Software Stack
  • Android Application Architecture & Components
  • Activity Lifecycle & State Management
  • Implicit and Explicit Intents
  • UI in Android: Controls, Menus, Navigation, Styles, Material Design
